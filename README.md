# Мій навчальний репозиторій

## Мета

Репозиторій містить навчальні макети HTML/CSS для практики семантичної розмітки, адаптивної верстки та компонентних стилів за методологією BEM.

## Технології

- HTML5
- CSS3 та CSS Grid/Flexbox
- Адаптивна верстка
- Методологія BEM

## Результат перевірки

- Макет перевірено в Google Chrome.
- Вбудоване YouTube-відео відповідає HTTP 200.
- Додано локальну обкладинку відеоплеєра.
- Горизонтальний скрол відсутній.
