# Домашня робота 8

## Мета

Створити адаптивний макет сторінки з секціями шапки, героя, опису, статистики та відео.

## Технології

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Методологія BEM

## Результат перевірки

- Макет перевірено в Google Chrome.
- Вбудоване YouTube-відео завантажується та доступне.
- Додано локальну обкладинку відеоплеєра.
- Горизонтальний скрол відсутній.
